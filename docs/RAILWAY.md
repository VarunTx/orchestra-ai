# Railway deployment (retired)

The hosted Railway deployment was retired. The default deployment is now the
local Docker Compose stack described in the README and `docs/DEPLOYMENT.md`.

- For the history of the Railway trial, hosted MCP endpoint and the reasons for
  leaving it, see `docs/PROGRESS.md`. Historical entries are not rewritten.
- For optional self-hosting on a VM, see `docs/DEPLOY_FREE.md`.
- The Railway connector remains a supported integration for reading a Railway
  account's inventory; it is unrelated to hosting Orchestra AI itself.

This note contains no setup instructions. The Railway project has not been
deleted by this documentation change.
